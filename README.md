
# Subscription Card Design

## Overview
This is a card design project I built using HTML and CSS to practise my frontend development skills.

## Tools and Techniques
- HTML5 for structuring the webpage.
- CSS3 for styling the card and button.
- CSS properties such as margin, padding, background colour, border radius, and box shadow.
- Hover effects and transitions for button interaction.

## What I Learned
I practised styling elements, adjusting spacing, adding shadows, and creating a hover effect with CSS. I also learned more about how different CSS properties affect the appearance of a webpage.

## Challenges
Getting the spacing and styling right was one of my main challenges. I worked through it by testing my code in the browser and adjusting the CSS.

## Areas for Improvement
I would like to improve my understanding of Flexbox, layout, and responsive design so I can create better designs on different screen sizes.
